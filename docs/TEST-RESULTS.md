## ملف Postman

اتنفذ الملف النهائي `MMKN.postman_collection.json` باستخدام **Newman 6.2.1، مشغل collections الخاص بـ Postman**. لم يتم تشغيل واجهة Postman Desktop في هذا التحقق.

**17 طلب، 36 assertion، صفر فشل.**

شمل التحقق: معرفات int، شكل الخدمة وiconUrl، تحميل الصور الثلاثة من روابط الرد الفعلية، الاستعلام الصحيح والأخطاء، رفض مبلغ مرسل للدفع، نجاح الدفع، إعادة نفس العملية بنفس المفتاح وبمفتاح آخر، منع إعادة الاستعلام لفاتورة مدفوعة، ووجود إيصال واحد في السجل.

لتجربته من Postman:

1. شغّل الباك إند من جديد لتصفير بيانات الديمو. اختبارات الدفع بتغيّر حالة الفاتورة، فلا تعيد المجموعة على نفس الحالة المدفوعة.
2. اعمل Import لملف `docs/MMKN.postman_collection.json`.
3. متغير `baseUrl` الافتراضي هو `http://localhost:8080`؛ عدّله لو الباك إند على عنوان مختلف.
4. افتح المجموعة واختر Run وشغّل كل الطلبات بالترتيب، مرة واحدة.

بديل من التيرمينال، والباك إند شغال في نافذة أخرى:

```powershell
npx --yes newman@6.2.1 run docs/MMKN.postman_collection.json
```

التقرير الخام للتشغيل المنفذ: `target/postman-results.json`. سجل الملخص: `target-postman-run.log`. ملفات target نواتج اختبار مؤقتة ومش جزء من ملف تسليم الـ API.
